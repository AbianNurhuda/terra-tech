6. DYNAMIC CMS PAGE
-------------------
Status: DONE dan VERIFIED untuk kasus production Project Availability.

Flow final:
  pathname
    -> navigation.path
    -> navigation.page
    -> navigation.page.slug
    -> GET /api/v1/pages/{slug}
    -> status published
    -> render title/content

DynamicCmsPage tidak lagi menjalankan flow:
  pathname -> slug

Tidak ada mapping hardcoded:
  /ProjectAvailability -> project-availability-1

Production data:
  navigation.path = /ProjectAvailability
  navigation.page_id = 2
  navigation.page.slug = project-availability-1
  page.status = published

DynamicCmsPage:
  - Mengambil public navigation.
  - Normalisasi path hanya untuk comparison.
  - Menolak navigation non-internal.
  - Menampilkan unavailable/404 jika navigation tidak ditemukan atau page null.
  - Mengambil slug dari navigation.page.slug.
  - Tidak memanggil /cms/pages/{id} dari public page.
  - Tidak memakai token CMS.
  - Tidak memakai localStorage sebagai source content Page.
  - Hanya render status published.
  - Menangani loading, 404, 403, error network/server, dan invalid URL.
